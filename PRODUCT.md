# Mega X product context

## Platform
Web. Marketing pages and an authenticated Phyntom X8 company console share one Vite project.

## Confirmed scope
The user requested moving all committed research workbench browser functionality into this frontend repository, preserving Mega X's existing style. Company-scoped stock research, tasks, reports, investment profiles, individual conversations and roundtables are the workflows. Existing company creation, switching, authentication and language selection are reused.

## Constraints
Backend interfaces remain in the platform project. Keep all migration work local; the user owns pushing. Chinese and English are the source feature languages. No real research or dialogue mutations during automated verification. Preserve existing marketing and console functionality.

## Success
All source workbench behavior is available in the company's console, builds independently of backend static workbench files, and passes tests and responsive browser checks.
